## 🌟 游戏核心特色

### 1. 真正的“高精视网膜（HD / 4K Ready）”画面与现代打击感
* **告别粗糙马赛克像素**：采用程序化高 DPI 矢量与高清着色管线，在 2K / 4K / MacBook Retina 屏幕上每一颗铆钉、履带链节、装甲高光均绝对锐利。
* **双轴独立平滑瞄准**：底盘 360° 真实差速转向与履带惯性物理，炮塔独立平滑旋转（支持键鼠精准瞄准与手机触控）。
* **战场真实互动与细节**：
  * 驶过泥泞留下的**持久高精履带压痕**；
  * 开火瞬间的炮口冲击波、火光与青烟；
  * 炮弹击碎砖墙时的多层物理碎屑、飞溅泥尘与弹坑；
  * 金属钛合金钢墙被普通子弹击中的**火花跳弹偏转（Ricochet）**。

### 2. 经典要素升级：老鹰基地 2.0 (Eagle Bastion)
* **拒绝一击暴毙**：经典老鹰基地新增**独立能量护盾与装甲生命值**，杜绝冷枪秒杀的挫败感。
* **基地科技改装**：
  * 可在战略中加装 **360° 自动化近防速射机炮** 协助清怪；
  * 加装 **自充能纳米护盾** 周期性自动回盾；
  * 经典铁锹道具：一键呼叫工兵将外围加固为绝对不可摧毁的钛合金白钢墙！

### 3. 肉鸽战备构筑体系（三选一抽卡 + 武器叠加进阶 Lv.1~Lv.5）
* **初始纯粹开局**：玩家开局仅配装标准穿甲重炮，其余高级主炮均通过战胜后的三选一卡牌抽选解锁。
* **六大多维元素主炮**：
  * ⚔️ **穿甲动能重炮**：高膛压穿甲弹，击穿砖墙，钢壁跳弹增伤（Lv.2+ 开放双联齐射）。
  * 💫 **高能棱镜光束**：强贯穿激光射线，在钢铁护壁与首领间发生高频折射。
  * ⚡ **球状闪电特斯拉**：沿途释放连锁电弧与 EMP 瘫痪震荡，极速清群。
  * 🌀 **烈风引力涡流**：聚能黑洞风暴，将敌军吸扯聚拢并偏折敌方炮火。
  * 🔥 **凝固汽油爆弹**：高爆破片点燃全图焦土地带，持续灼烧重型装甲。
  * ❄️ **低温绝对冷冻**：发射深冷碎冰弹，大范围冰冻并减速敌坦机动性。
* **武器多重叠加升级**：重复抽取相同主炮可一路进阶强化至 **Lv.5**，大幅提升单发威力（每级 +35%）、缩减冷却（每级 -16%）并扩展元素异能覆盖面。
* **20+ 种被动质变战术芯片**：吸血死灵回收、能量护盾发生器、复合钛钢装甲、双联火炮、自动速射装填等。

### 4. 尖塔式 16 层战役沙盘大地图（16-Floor Campaign Map）
* 包含 10 余种战术地形（莱茵水堑、巷战迷宫、热带密林、极地冰原与钛金要塞等）：
  * ⚔️ **常规装甲遭遇战**：与轻型侦察、突击双联、重装猛犸及导弹战车集群交火；
  * 💀 **三大精英指挥官首领战（独立顶部大血条 & 专属弹幕机制）**：
    * **第 4 层（Floor 3）· 烈焰掠食者指挥官「伊格尼斯」**：三向散射爆炎火炮 + 投掷跳雷阵地 + 狂暴加速冲撞；
    * **第 8 层（Floor 7）· 雷暴泰坦破坏者「特斯拉」**：8 向环形等离子风暴弹幕 + 狙击电磁轨道炮 + EMP 脉冲震荡；
    * **第 12 层（Floor 11）· 虚空使徒「引力巨擘」**：旋转向外扩散的繁星螺旋弹幕 + 范围黑洞引力弹；
  * 👑 **第 16 层（Floor 15）· 终局首领：陆上巡洋舰「歌利亚」（Goliath MK-IV）**：
    * **Phase 1**：203mm 破墙重型 AP 主炮 + 双侧追踪巡航导弹齐射；
    * **Phase 2**：360° 旋转弹幕地狱风暴（Danmaku Spiral Hell） + 移速过载提升；
    * **Phase 3**：高能全屏扫射死亡激光 + 密集螺旋弹幕覆盖；
  * 🛒 **黑市军械库**：消耗战地零件选购芯片、大修装甲、加固要塞防线；
  * ⛺ **地下掩蔽营火**：在交火间隙选择【抢修休整】恢复 70% 生命与要塞加固，或【车床锻造】升级主炮星级；
  * ❓ **战地突发机密**：高风险高收益事件抉择。
* **关卡胜利补满机制**：每关战役结束后自动 100% 修复战车装甲与能量护盾，消除残血压力。

## 🕹️ 键位与操作指南

| 操作 | PC 键鼠 | 说明 / 移动端 |
| :--- | :--- | :--- |
| **驾驶底盘移动** | **W / A / S / D** 或 **方向键** | 360° 惯性差速移动 |
| **炮塔瞄准** | **鼠标光标移动** | 独立于车体朝向瞄准（支持触屏拖拽） |
| **主炮开火** | **鼠标左键** / **空格键** | 发射当前装备主炮 |
| **战术喷射冲刺** | **空格键 (Space)** 或 **Shift** | 瞬时加速 + 无敌帧完美闪避（CD 1.5s） |
| **切换主炮武器** | **数字键 1 ~ 6** 或 **鼠标滚轮** | 切换已在战利品中解锁的武器系统 |
| **自动瞄准 / 开火** | **屏幕顶部状态栏按钮** | 可随时开启/关闭辅助火控，仅需操控方向 |
| **音乐开关** | **屏幕右上角静音按钮** | 实时静音/开启自适应背景战役配乐 |

## 🛠️ 本地开发与构建

本项目采用 **Vite + TypeScript + 原生 Web Audio + High-DPI Canvas** 打造，零大型第三方臃肿引擎包，即开即玩：

```bash
# 1. 安装依赖
npm install

# 2. 启动本地热重载开发服务器
npm run dev

# 3. 类型检查并编译打包到 dist/ 目录
npm run build

# 4. 本地预览打包产物
npm run preview
```
