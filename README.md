## 🌟 游戏核心特色

### 1. 真正的“高精视网膜（HD / 4K Ready）”画面与现代打击感
* **告别粗糙马赛克像素**：采用程序化高 DPI 矢量与高清着色管线，在 2K / 4K / MacBook Retina 屏幕上每一颗铆钉、履带链节、装甲高光均绝对锐利。
* **双轴独立平滑瞄准**：底盘 360° 真实差速转向与履带惯性物理，炮塔独立平滑旋转（支持键鼠精准瞄准与手机触控）。
* **战场真实互动与细节**：
  * 驶过泥泞留下的**持久高精履带压痕**；
  * 开火瞬间的炮口冲击波、火光与青烟；
  * 炮弹击碎砖墙时的多层物理碎屑、飞溅泥尘与弹坑；
  * 金属钛合金钢墙被普通子弹击中的**火花跳弹偏转（Ricochet）**。

### 2. 经典要素升级：老鹰基地 2.0 (Eagle Bastion)
* **拒绝一击暴毙**：经典老鹰基地新增**独立能量护盾与装甲生命值**，杜绝冷枪秒杀的挫败感。
* **基地科技改装**：
  * 可在战略中加装 **360° 自动化近防速射机炮** 协助清怪；
  * 加装 **自充能纳米护盾** 周期性自动回盾；
  * 经典铁锹道具：一键呼叫工兵将外围加固为绝对不可摧毁的钛合金白钢墙！

### 3. 肉鸽构筑体系（18+ 种质变芯片自由组合）
* **四维改装维度**：底盘、炮塔、弹道改质、战术技能。
* **典型质变流派**：
  * **跳弹动能流**：双联炮 + 弹射反弹 + 破钢穿甲，在掩体窄道中盲射倾泻弹幕，反弹持续增伤。
  * **重装推土机流**：重型撞角 + 涡轮引擎 + 战术超燃推进，直接高速撞穿整张地图的红砖墙开路，贴脸将敌坦撞成废铁。
  * **电磁激光控场流**：高能穿透磁轨炮 + 特斯拉电弧闪电链，一炮贯穿全图并连锁瘫痪成片敌军。
  * **全地形水陆漂移流**：悬浮气垫底盘，直接无视河流阻隔漂浮冲锋，并在冰面上灵活漂移。

### 4. 尖塔式战役路线（Campaign Map）
* 5 层递进作战节点：
  * ⚔️ **前哨遭遇战**：清剿先遣巡逻分队；
  * 💀 **重装精英战**：硬核四星重型猛犸战车，高风险高掉落；
  * 🛒 **黑市军械库**：消耗战斗拾取的零件齿轮购买芯片、大修装甲、加固基地；
  * ❓ **战地突发机密**：高风险决策事件；
  * ⛺ **战地整备所**：全面大修或主炮火控升级；
  * 👑 **终极要塞决战**：巨型多炮塔陆上巡洋舰「歌利亚」（多部位破坏、主炮迫击曲射、狂暴二阶段）。

## 🕹️ 键位与操作指南

| 操作 | PC 键鼠 | 移动端触屏 |
| :--- | :--- | :--- |
| **驾驶底盘移动** | **W / A / S / D** 或 **方向键** | 屏幕左下角虚拟十字方向键 |
| **瞄准方向** | **鼠标指针移动**（360°独立） | 沿移动方向或触控自动校准 |
| **主炮开火** | **鼠标左键** 或 **空格键** | 屏幕右下角「开火」按钮 |
| **战术喷射冲刺** | **Shift** 或 **鼠标右键** / **F** | 屏幕右下角「冲刺」按钮 |
| **战术休整 / 选项** | **鼠标点击交互** | 屏幕轻触卡牌与路线节点 |

## 🛠️ 本地开发与构建

本项目采用 **Vite + TypeScript + 原生 Web Audio + High-DPI Canvas** 打造，零大型第三方臃肿引擎包，即开即玩：

```bash
# 1. 安装依赖
npm install

# 2. 启动本地热重载开发服务器
npm run dev

# 3. 类型检查并编译打包到 dist/ 目录
npm run build

# 4. 本地预览打包产物
npm run preview
```
